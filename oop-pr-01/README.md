# ПР1 — Концепция приложения и вёрстка виджетов

Запустите приложение и проверьте вкладки «Места», «Избранное», «Настройки». Введите часть названия в поле поиска. Вывод обработчика виден в консоли Flutter. На карточке нажмите кнопку сердечка и откройте «Избранное».

## Запуск

Flutter 3.32.0, Dart 3.8.0 и настроенный Android SDK. Для проверки использован Android 15 (API 35).
На Windows для команд Flutter используйте путь без кириллицы, например через junction диска.

```text
flutter pub get
flutter run -d emulator-5554
```
